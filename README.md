- HTML5 — Website structure and content
- CSS3 — Styling, responsive layouts, and hover effects
- JavaScript — Mobile navigation, active navigation links, and scroll animations
- GitHub — Source code hosting
- GitHub Pages — Website deployment

## Features

- Responsive design for desktop and mobile devices
- Professional homepage and introduction

- Technical skills overview
- Five featured development projects
- Development Experience section
- Interactive mobile navigation

## How to Run Locally

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in a browser or use the Live Server extension.
4. Navigate through the website.
